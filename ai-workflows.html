Frequently asked questions

What AI workflows can I run on Fundline?

Ready-made multi-step workflows for freelancers and businesses: client research, proposals and scope of work, CV plus freelance gig matching, SEO briefs and audits, crypto and tokenomics research, competitor analysis, and more. Each returns a structured, ready-to-use result.

How much does an AI workflow cost?

You pay per run in USDC, typically from 0.01 to 0.12 USDC depending on the workflow and quality tier. There is no subscription; you only pay when you run one.

Why use Fundline instead of plain ChatGPT?

Workflows are pre-engineered multi-step chains that pull real data (live web search, real freelance gig listings) and return structured deliverables like a PDF CV or a Word report. You fill a form instead of prompt engineering, and pay per use.

Can an AI agent run a workflow automatically?

Yes. Fundline exposes an HTTP API and a Model Context Protocol (MCP) endpoint. An AI agent can discover workflows and run them, paying per run from its own wallet via x402, with no account required.

How do I pay for a run?

From your connected wallet in USDC on Arc. Payment is held by a non-custodial per-run escrow and refunded automatically if the run fails.
