How it works

Invoice to receipt in three steps

01 Create your invoice

Add client, amount, and due date. Your invoice is a single shareable link at /pay/:id, ready in seconds.

02 Client pays from any chain

They connect a wallet and pay USDC from Arc, Ethereum, or Base. The payment goes straight to your wallet, not through Fundline.

03 Fundline confirms it arrived

Arcscan checks the transaction on-chain. Once confirmed, the invoice flips to paid and you get a PDF receipt and Telegram alert.

Features

Everything you need to bill in USDC

Payments

The payment goes wallet to wallet

USDC transfers from your client's wallet directly to yours. Nothing passes through Fundline; the contract holds no balance at any point.

Settlement

Your client pays from any chain

They can pay from Ethereum or Base and the USDC still lands on Arc, real and unwrapped, in one flow. No manual bridging required.

Agents

Let software pay per request

Software and AI agents can create invoices, receive payment links, and get pinged the moment payment confirms, all via the REST API.

Security

Verified on-chain before marked paid

The paid status is only set after a matching on-chain transaction is found and confirmed. No confirmed transaction, no paid status.

Build on Fundline

The API does what the dashboard does.

Create invoices, receive a payment event the moment a transaction confirms, and let agents pay per request, all from the REST API.

Create an invoice via API

POST /api/agent/invoices
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json

{
  "merchantWallet": "0xYourWalletAddress",
  "clientName": "Acme Corp",
  "amount": "500",
  "currency": "USDC",
  "dueDate": "2026-07-01",
  "description": "Design services - June 2026"
}

Your system receives a invoice.paid webhook the moment payment confirms on-chain. Full payload and signature verification in the docs.

Creators: sell pay-per-item products via storefront at /s/:slug, no API key required.

FAQ

Frequently asked questions

USDC (USD Coin) is a regulated stablecoin issued by Circle, pegged 1:1 to the US dollar. It is backed by fully reserved assets and is one of the most widely used digital dollars. Fundline uses native USDC on Arc Testnet for all settlements.

Any EVM-compatible wallet works: MetaMask, Rabby, Coinbase Wallet, or any wallet that supports custom RPC networks. You will need to add the Arc Testnet network and hold some testnet USDC. The documentation has step-by-step wallet setup instructions.

Fundline is currently live on Arc Testnet. A mainnet launch date has not been announced. Follow the project on social channels for updates. All testnet features will carry over to mainnet.

Fundline itself charges no fees on testnet. You only pay the network gas cost for each on-chain transaction, which is minimal on Arc Testnet. Mainnet fees have not been announced and will be disclosed before launch.
